# Mini ERP Stock & Sales

مشروع اختبار عملي باستخدام CodeIgniter 3.1.13 وPHP وMySQL أو MariaDB.
يدير المنتجات والمخزون وفواتير البيع والصلاحيات والتقارير. الواجهة عربية باتجاه RTL.

## متطلبات التشغيل

- PHP بإصدار 7.4 أو أحدث، بنسخة 64-bit. الاختبار الفعلي هنا على PHP 7.4.33.
- إضافة mysqli، وإضافات PHP القياسية: session وjson وfilter وctype.
- MySQL أو MariaDB مع دعم InnoDB وutf8mb4؛ اختُبر MySQL 5.7.40.
- متصفح حديث يدعم JavaScript وBigInt وdialog. للطباعة استخدم Chrome أو Edge.
- مجلد PHP المؤقت يجب أن يكون قابلًا للكتابة لحفظ الجلسات خارج مجلد الويب.

ملفات CodeIgniter موجودة داخل المشروع؛ لا يلزم تنزيل الإطار أو تشغيل Composer للتشغيل.
تأكد من أن أمر `php -v` يشير إلى النسخة التي تريد استخدامها.

## التشغيل من نسخة جديدة

نفذ الأوامر التالية من مجلد المشروع. لا تستورد الملفات في قاعدة بيانات مستخدمة.

### 1. إنشاء قاعدة البيانات

يمكنك الاستيراد عبر phpMyAdmin أو فتح عميل MySQL:

```text
mysql --default-character-set=utf8mb4 -u root -p
```

داخل العميل:

```sql
CREATE DATABASE smart_life_test CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE smart_life_test;
SOURCE database/schema.sql;
SOURCE database/seed.sql;
```

إذا لم يكن حسابك root، استبدله بحساب MySQL المناسب. عند كلمة مرور فارغة اضغط Enter.
استخدم مسارات مطلقة بشرطات `/` في أوامر SOURCE إذا لم يعمل المسار النسبي.
ملف seed اختياري ويضيف مستودعين وثلاثة منتجات وعميلين وكميات تجريبية، دون مستخدمين أو فواتير.

### 2. إعداد الاتصال المحلي

من PowerShell:

```powershell
Copy-Item application/config/development/database.php.example application/config/development/database.php
```

هذا الأمر لنسخة جديدة فقط؛ لا تستبدل ملف اتصال محلي موجود.
عدّل hostname وport وusername وpassword وdatabase في الملف المنسوخ حسب بيئتك،
أو استخدم متغيرات البيئة التي يقرأها المثال:

```powershell
$env:APP_DB_HOST = '127.0.0.1'
$env:APP_DB_PORT = '3306'
$env:APP_DB_USER = 'root'
$env:APP_DB_NAME = 'smart_life_test'
```

لكلمة مرور غير فارغة اضبط APP_DB_PASSWORD محليًا أو عدّل قيمة password في الملف المنسوخ.
ملف database.php المحلي مستثنى من Git، أما ملف المثال فلا يحتوي على بيانات اتصال خاصة.

### 3. إنشاء حسابات الدخول

```powershell
php tools/create_user.php admin admin
php tools/create_user.php warehouse1 warehouse_user 1
```

يعرض كل أمر كلمة مرور عشوائية جديدة؛ احتفظ بها للدخول. يُخزن hash فقط في قاعدة البيانات.
الأمر لا يغيّر حسابًا موجودًا. الرقم 1 هو معرّف المستودع الرئيسي في البيانات التجريبية.
لا توجد كلمات مرور افتراضية أو حسابات جاهزة ضمن ملفات SQL.

### 4. فحص الاتصال ثم التشغيل

```powershell
php tools/check_database.php
php -S 127.0.0.1:8000 -t .
```

افتح [تسجيل الدخول](http://127.0.0.1:8000/index.php/auth/login).
اترك نافذة الخادم مفتوحة، واستخدم Ctrl+C لإيقافه. الخادم المدمج للتطوير المحلي.

إذا لم يكن PHP في PATH، استخدم مساره الكامل بدل php. مثال لجهاز Wamp الحالي:

```powershell
& 'D:\wamp64\bin\php\php7.4.33\php.exe' -S 127.0.0.1:8000 -t .
```

عند استخدام منفذ أو رابط آخر، اضبط APP_BASE_URL قبل إنشاء الحسابات أو تشغيل الخادم:

```powershell
$env:APP_BASE_URL = 'http://127.0.0.1:8001/'
php -S 127.0.0.1:8001 -t .
```

القيمة الافتراضية هي http://127.0.0.1:8000/ ويجب أن ينتهي العنوان بشرطة `/`.

## تجربة الاستخدام

1. ادخل بحساب المدير وأضف منتجًا من قسم المنتجات.
2. افتح تحديد المخزون، واختر المنتج والمستودع، ثم أدخل الكمية النهائية وحد التنبيه.
3. أنشئ فاتورة، واختر العميل والمستودع، وابحث عن المنتجات وحدد الكميات والخصم.
4. احفظ الفاتورة وراجع تفاصيلها واسم منشئها، ثم راجع رصيد المخزون المتبقي.
5. ادخل بمستخدم المستودع للتحقق من اقتصار المخزون والفواتير على مستودعه.

المدير يدير المنتجات ويسوي الأرصدة ويرى المستودعات كلها. مستخدم المستودع يرى
المنتجات للقراءة وينشئ المبيعات ويعرض المخزون والفواتير والتقارير الخاصة بمستودعه.

## البحث والتصدير والطباعة

- البحث والفلاتر في المنتجات والمخزون تُنفذ بأزرارها فقط، دون تحميل الصفحة أو تغيير عنوانها.
- تعرض صفحة المنتجات 15 نتيجة وصفحة المخزون 20 نتيجة؛ أرقام الصفحات وأزرار السابق والتالي تحتفظ بالفلاتر المطبقة.
- ملف database/demo_products.sql اختياري لإضافة 20 منتجًا تجريبيًا بأكواد UI-DEMO لإظهار تقسيم الصفحات؛ لا يعدّل المنتجات الموجودة ولا يضيف كميات مخزون.
- رسائل النجاح والأخطاء نصوص داخل الصفحة؛ التأكيدات فقط نوافذ منبثقة.
- تصدير المخزون المنخفض يشمل كل الصفحات وفق البحث والمستودع المطبقين، ويطبق دائمًا quantity <= alert_quantity.
- تصدير الفواتير متاح لملخص القائمة كاملة أو لفاتورة واحدة مع سطورها.
- ملفات CSV تدعم العربية في Excel باستخدام UTF-8 BOM، مع حماية النصوص من صيغ جداول البيانات.
- من تفاصيل الفاتورة اضغط طباعة / حفظ PDF، ثم اختر الطابعة أو حفظ PDF من نافذة المتصفح.
- تنسيق الطباعة A4 يخفي التنقل والأزرار. الحفظ PDF يتم من المتصفح، وليس تنزيل PDF مباشرًا من الخادم.

## التحقق من نسخة نظيفة

توجد أداة مستقلة تستخدم Python 3 ومكتباته القياسية. تحتاج PHP وعميل MySQL وحسابًا
مسموحًا له إنشاء قاعدة اختبار وحذفها. لا تحتاج تثبيت حزم Python.

```powershell
python tools/verify_clean_install.py --php php --mysql mysql
```

مثال للمسارات الحالية على Windows:

```powershell
python tools/verify_clean_install.py --php 'D:\wamp64\bin\php\php7.4.33\php.exe' --mysql 'D:\wamp64\bin\mysql\mysql5.7.40\bin\mysql.exe'
```

يمكن تمرير --host و--port و--user، وتؤخذ كلمة المرور من APP_DB_PASSWORD.
الأداة تنشئ نسخة مؤقتة دون إعداد الاتصال الحالي أو سجلاته، وقاعدة باسم عشوائي يبدأ
بـ mini_erp_clean_، وتستورد SQL وتُنشئ حسابات وتختبر التشغيل والبيع والتصدير، ثم توقف
خادم الاختبار وتحذف قاعدته والنسخة المؤقتة. لا تستخدم قاعدة المشروع أو حساباته.
تفاصيل نتيجة التشغيل الفعلية في docs/clean-install.md.

## حل مشاكل التشغيل الشائعة

- خطأ الاتصال: راجع اسم القاعدة والمنفذ وبيانات المستخدم ووجود mysqli.
- روابط بمنفذ خاطئ: راجع APP_BASE_URL ثم أعد تشغيل خادم PHP.
- Permission denied للجلسات: تأكد من قابلية مجلد PHP المؤقت للكتابة.
- تنسيق قديم بعد التعديلات: استخدم Ctrl+F5.
- صفحة الفاتورة لا تضيف منتجات: تأكد من تفعيل JavaScript واختيار مستودع وربط المنتج بمخزون فيه.
- أمر mysql أو php غير معروف: أضفه إلى PATH أو استخدم المسار الكامل للملف التنفيذي.

تهيئة Git والـcommits والرفع وتسليم الرابط مرحلة لم تُنجز بعد.
